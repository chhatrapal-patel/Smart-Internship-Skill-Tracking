# 🎓 Smart Internship & Skill Tracking Management System

A full-stack web-based platform that helps students **discover internships, manage skills, apply for opportunities, and track applications** through a centralized system.

The platform provides separate modules for **Students, Companies, and Administrators**.

## 📌 Features

### 👨‍🎓 Student

* Registration and login
* Profile and skill management
* Browse and search internships
* Apply for internships
* Track application status

### 🏢 Company

* Company registration and profile
* Create and manage internships
* View and manage applicants
* Track recruitment activities

### 🛡️ Admin

* Manage students and companies
* Manage internship listings
* Monitor platform activities
* Manage application data

## 🔄 Workflow

```text
Student → Register → Profile → Skills → Browse Internships
        → Apply → Track Application

Company → Register → Profile → Post Internship
        → Review Applicants → Manage Applications

Admin → Login → Dashboard → Manage Users & Internships
```

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

### 2. Start Backend

```bash
cd server
npm install
npm start
```

### 3. Start Frontend

Open another terminal:

```bash
cd ui
npm install
npm run dev
```

The frontend will normally run at:

```text
http://localhost:5173
```
